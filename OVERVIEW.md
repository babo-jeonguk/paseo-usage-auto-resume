Usage Auto Resume continues the same Codex or Claude Main agent after a provider usage limit resets. It handles session and weekly limits when the provider notice or account usage information supplies the reset time, and schedules a continue prompt two minutes after that time.

The Auto Resume sidebar screen lists pending resumes by day, with the send time, countdown, agent title, provider and workspace. Open a row to return to the conversation. Each reservation starts enabled; its switch takes effect immediately and can be turned back on before the scheduled time.

Requires Paseo daemon and app 0.11.x, with plugins enabled. Only the exact provider IDs `codex` and `claude-main` are supported. For Claude, configure a provider named `claude-main` extending `claude`; the standard `claude` ID and other aliases are not handled. The plugin uses the accounts already signed in through their CLIs.

To match account usage, the daemon reads the account email from Claude's `.claude.json` or the email claims in Codex's `auth.json`, using the configured `CLAUDE_CONFIG_DIR` or `CODEX_HOME`. It reads agent state, recent timeline notices and Paseo usage information, stores resume jobs under `PASEO_HOME/plugin-data/usage-auto-resume/jobs.json`, and sends a fixed continue prompt to the existing agent through Paseo. The prompt asks the parent to continue unfinished work and any unfinished subagents stopped by the limit. Login tokens are not included in saved jobs, logs or the continue prompt.

A new turn, a newer user message, an archived or closed agent, or an agent running or awaiting permission cancels the resume. Reservations survive restarts, but need a lifecycle event or the Auto Resume screen to supply the API before they can run again. If the reset time remains unknown, the plugin rechecks after 15 minutes and may retry the continue prompt, stopping after 24 consecutive unsuccessful automatic continues. Context overflow and billing failures are excluded. Subagent continuation depends on the parent's available provider tools.
